01 · Comprendre

Le rôle du switch et du routeur

Un switch relie principalement les équipements d'un même réseau local. Il apprend les adresses MAC et utilise sa table de commutation pour transmettre les trames vers le bon port.

Un routeur relie des réseaux IP différents. Sa table de routage détermine par quelle interface et vers quelle passerelle un paquet doit être envoyé.

01

Commutation

Le switch travaille sur le réseau local et associe les adresses MAC aux ports.

02

Routage

Le routeur choisit un chemin entre différents réseaux IP.

03

Segmentation

Les VLAN permettent de séparer logiquement plusieurs domaines de broadcast.

💡 À retenir
Le switch connecte et segmente le réseau local ; le routeur permet la communication entre réseaux distincts.
02 · VLAN

Créer une séparation logique du réseau

Un VLAN permet de regrouper logiquement des ports d'un switch afin de créer plusieurs réseaux indépendants sur une même infrastructure physique.

03 · Interfaces

Configurer les interfaces

La configuration d'une interface consiste notamment à sélectionner le port, lui attribuer son rôle et, lorsqu'il s'agit d'une interface routée, définir son adressage IP.

Exemple de configuration d'un port d'accès dans un VLAN :

enable configure terminal interface GigabitEthernet0/1 switchport mode access switchport access vlan 10 no shutdown

Exemple d'activation d'une interface avec une adresse IP :

enable configure terminal interface GigabitEthernet0/0 ip address 192.168.10.1 255.255.255.0 no shutdown
⚠️ Attention
Une interface administrativement désactivée ne pourra pas assurer le trafic attendu. Vérifier l'état de l'interface après configuration.

05 · Trunking

Transporter plusieurs VLAN

Un lien trunk transporte plusieurs VLAN entre équipements réseau. Il est particulièrement utile entre switches ou entre un switch et un routeur lorsque plusieurs VLAN doivent traverser le même lien physique.

06 · Configuration

Sauvegarder la configuration

Après une modification validée, la configuration doit être conservée afin qu'elle puisse être restaurée ou réutilisée après un redémarrage ou une intervention.

RAM

Configuration courante

Représente l'état actuellement utilisé par l'équipement.

NVR

Configuration sauvegardée

Permet de conserver la configuration nécessaire au redémarrage.

BK

Copie externe

Une copie contrôlée facilite la restauration et la traçabilité.

copy running-config startup-config
Pourquoi vérifier après sauvegarde ?

La vérification permet de confirmer que les paramètres attendus sont présents et que la sauvegarde correspond bien à l'état souhaité de l'équipement.

Points clés à retenir

08 · Repères

Questions fréquentes

Quelle est la différence entre un port access et un port trunk ?

Un port access est généralement associé à un seul VLAN pour les équipements terminaux. Un port trunk transporte plusieurs VLAN entre équipements réseau.

Pourquoi utiliser plusieurs VLAN ?

Ils permettent de séparer logiquement des groupes d'équipements et de mieux structurer les domaines de broadcast.

À quoi sert la table de routage ?

Elle fournit au routeur les informations nécessaires pour sélectionner une destination et une sortie adaptées à chaque réseau connu.

Pourquoi sauvegarder la configuration ?

Pour conserver les paramètres validés et permettre à l'équipement de retrouver une configuration opérationnelle après un redémarrage.
