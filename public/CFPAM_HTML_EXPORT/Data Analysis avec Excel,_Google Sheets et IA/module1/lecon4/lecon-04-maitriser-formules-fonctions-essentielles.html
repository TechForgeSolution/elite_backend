1. Anatomie et logique d'une formule

Une formule est un calcul que le tableur effectue pour vous. Elle commence toujours par le signe =. Quand les données changent, le résultat se met à jour automatiquement.

➕

Opérateurs arithmétiques

+ − * / ^ pour additionner, soustraire, multiplier, diviser, élever à une puissance.

⚖️

Opérateurs de comparaison

= < > <= >= <> donnent VRAI ou FAUX.

🔗

Opérateur de texte

& assemble deux textes en un seul.

// Formule simple avec opérateurs et références de cellules
=B2*C2       // quantité × prix
=B2*C2*1,2   // avec 20 % de TVA
💡 À retenir

On écrit des références de cellules (B2) plutôt que des valeurs fixes : la formule reste valable quand les données évoluent.

2. Les fonctions d'agrégation de base

Elles résument une plage de cellules en une seule valeur. Elles s'appliquent ici à une colonne de montants en B2:B10.

FonctionCe qu'elle calculeExemple
SOMMELe total=SOMME(B2:B10)
MOYENNELa moyenne=MOYENNE(B2:B10)
MINLa plus petite valeur=MIN(B2:B10)
MAXLa plus grande valeur=MAX(B2:B10)
NBLe nombre de cellules contenant un nombre=NB(B2:B10)
Quelle différence entre NB et NBVAL ?

NB (COUNT) ne compte que les cellules contenant des nombres. NBVAL (COUNTA) compte toutes les cellules non vides, texte compris.

⚠️ Attention

Ces fonctions ignorent les nombres stockés en texte (voir leçon 03) : un total trop faible est souvent le signe d'un problème de format.

3. La logique conditionnelle : la fonction SI

SI teste une condition et renvoie un résultat si elle est vraie, un autre si elle est fausse. Sa structure : SI(test ; valeur_si_vrai ; valeur_si_faux).

// Deux issues possibles
=SI(B2>=1000;"Objectif atteint";"À améliorer")

Pour plus de deux issues, on place un SI à l'intérieur d'un autre. Les tests sont évalués dans l'ordre.

// Trois niveaux de performance
=SI(B2>=1000;"Excellent";SI(B2>=500;"Correct";"Faible"))
⚠️ Erreur fréquente

Dans une série de SI imbriqués, l'ordre des tests compte : placez la condition la plus stricte en premier, sinon une valeur de 1200 serait classée « Correct ».

4. Calculs sous conditions multiples

Pour calculer uniquement sur les lignes qui répondent à un ou plusieurs critères, on utilise les fonctions « .SI.ENS ». Elles s'appuient sur ce tableau de ventes, placé en A1:D7 :

A : RégionB : ProduitC : MoisD : Ventes (€)
NordCahierJanvier400
NordStyloJanvier150
SudCahierJanvier300
SudCahierFévrier500
NordCahierFévrier450
SudStyloFévrier200

Additionne les ventes qui respectent tous les critères. Syntaxe : plage à additionner, puis des paires plage de critère / critère. Équivalent anglais : SUMIFS.

// Ventes de cahiers dans la région Nord
=SOMME.SI.ENS(D2:D7;A2:A7;"Nord";B2:B7;"Cahier")
// Résultat : 850

Compte les lignes qui respectent tous les critères. Équivalent anglais : COUNTIFS.

// Nombre de ventes dans la région Sud en février
=NB.SI.ENS(A2:A7;"Sud";C2:C7;"Février")
// Résultat : 2

Calcule la moyenne des valeurs qui respectent un critère. Syntaxe : plage du critère, critère, plage à moyenner. Équivalent anglais : AVERAGEIF.

// Vente moyenne de la région Nord
=MOYENNE.SI(A2:A7;"Nord";D2:D7)
// Résultat : 333,33 (arrondi)
📊 Bonne pratique d'analyse

Placez les critères dans des cellules (par exemple F1 pour « Nord ») plutôt que dans la formule : vous changez le critère sans réécrire la formule.

5. Les fonctions de recherche

Elles retrouvent une information dans un tableau à partir d'une clé, comme un identifiant ou un nom de produit. Exemple : retrouver le prix d'un produit dans une liste de tarifs (A2:B5 ci-dessous).

A : ProduitB : Prix (€)
Cahier2,50
Stylo1,20
Classeur4,90
Règle0,80

Cherche la valeur dans la première colonne du tableau et renvoie la valeur de la colonne dont on donne le numéro.

// RECHERCHEV(valeur ; tableau ; n° de colonne ; correspondance exacte)
=RECHERCHEV("Stylo";A2:B5;2;FAUX)
// Résultat : 1,20

Cherche dans une colonne et renvoie la valeur correspondante d'une autre colonne, sans compter de numéro de colonne.

// RECHERCHEX(valeur ; où chercher ; quoi renvoyer ; si non trouvé)
=RECHERCHEX("Stylo";A2:A5;B2:B5;"Absent")
// Résultat : 1,20
CritèreRECHERCHEVRECHERCHEX
Sens de rechercheVers la droite uniquementDans les deux sens
Colonne de résultatDésignée par un numéro, fragile si on insère une colonneDésignée par une plage, plus robuste
Valeur introuvableRenvoie #N/AMessage personnalisable
DisponibilitéToutes versionsExcel 2021 / 365 et Google Sheets
💡 À retenir

RECHERCHEX est recommandée quand elle est disponible. RECHERCHEV reste très répandue dans les fichiers existants : il faut savoir la lire. Utilisez toujours la correspondance exacte (FAUX) pour éviter des résultats erronés.

6. Identifier et résoudre les erreurs courantes

Un message d'erreur n'est pas un échec : il indique précisément ce qui ne va pas dans la formule. Les quatre plus fréquents :

MessageSignificationPiste de correction
#N/AValeur introuvableVérifier l'orthographe et les espaces cachés (SUPPRESPACE)
#REF!Référence invalideUne ligne ou colonne citée a été supprimée : recréer la référence
#VALEUR!Type de donnée incorrectUn texte est utilisé dans un calcul : convertir en nombre
#NOM?Nom de fonction non reconnuCorriger une faute de frappe ou la langue de la fonction
Masquer une erreur attendue avec SIERREUR

Quand une erreur est normale (produit absent de la liste, par exemple), SIERREUR affiche un message clair à la place.

=SIERREUR(RECHERCHEV("Gomme";A2:B5;2;FAUX);"Produit inconnu")
⚠️ Attention

N'utilisez pas SIERREUR pour tout cacher : une erreur inattendue masquée est une erreur qu'on ne corrigera jamais.

7. L'IA pour rédiger, expliquer et déboguer une formule

Un assistant d'IA (Copilot, Gemini, ChatGPT) peut transformer une description en formule, expliquer une formule héritée d'un collègue ou chercher l'origine d'une erreur. Plus la description est précise (colonnes, plages, résultat attendu), plus la proposition est pertinente.

Décrire le besoin en langage courant, en précisant les colonnes concernées.

Exemple de demande : « Écris une formule qui additionne les ventes (colonne D) de la région Nord (colonne A) pour les cahiers (colonne B). »

Coller une formule existante et demander une explication étape par étape, utile pour reprendre un fichier hérité.

Fournir la formule, le message d'erreur obtenu et un exemple de donnée. L'IA propose alors des causes probables.

Points clés à retenir

  • Une formule commence par « = » et combine opérateurs, fonctions et références de cellules.
  • SOMME, MOYENNE, MIN, MAX et NB résument une plage de données.
  • SI renvoie un résultat selon un test ; avec des SI imbriqués, l'ordre des conditions est décisif.
  • SOMME.SI.ENS, NB.SI.ENS et MOYENNE.SI calculent uniquement sur les lignes qui respectent des critères.
  • RECHERCHEX est plus souple et plus robuste que RECHERCHEV, que l'on doit toutefois savoir lire.
  • Chaque message d'erreur (#N/A, #REF!, #VALEUR!, #NOM?) pointe vers une cause précise.
  • Une formule proposée par l'IA se teste toujours sur un cas dont le résultat est connu.
