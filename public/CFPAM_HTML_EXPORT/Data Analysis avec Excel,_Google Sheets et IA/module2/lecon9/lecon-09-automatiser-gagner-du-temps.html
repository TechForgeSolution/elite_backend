1. Les modèles réutilisables

Une analyse refaite chaque mois (ventes, budget, suivi de stock) reprend presque toujours la même structure : mêmes colonnes, mêmes formules, même mise en forme. Un modèle (template) conserve cette structure prête à l'emploi : on l'ouvre, on y place les nouvelles données, et tout le reste est déjà en place.

📐

Structure figée

Colonnes, en-têtes et mise en forme identiques à chaque utilisation.

🧮

Formules intégrées

Totaux, moyennes et pourcentages se calculent dès la saisie.

📊

Graphiques prêts

Les graphiques se mettent à jour avec les nouvelles données.

✅

Analyses homogènes

Toute l'équipe travaille avec le même format.

  • On construit le classeur, puis on l'enregistre au format Modèle Excel (.xltx).
  • Un double-clic sur ce fichier ouvre une copie vierge : le modèle d'origine reste intact.
  • Les modèles proposés par Excel sont accessibles depuis Fichier › Nouveau.
  • On prépare une feuille de référence, puis on utilise Fichier › Créer une copie à chaque nouvelle période.
  • La galerie de modèles propose des structures prêtes à l'emploi (budget, planning, suivi).
  • Les organisations peuvent publier leurs propres modèles pour toute l'équipe.
📊 Bonne pratique d'analyse

Videz les données d'exemple avant d'enregistrer un modèle, mais gardez les formules et les en-têtes : un bon modèle ne contient que la structure.

2. Raccourcis clavier et séries automatiques

Chaque geste évité à la souris économise quelques secondes ; répétés des centaines de fois, ils représentent un gain réel. Voici les raccourcis les plus utiles, valables dans Excel comme dans Google Sheets.

Raccourcis clavier essentiels des tableurs
RaccourciEffet
Ctrl + C / X / VCopier, couper, coller
Ctrl + Z / YAnnuler, rétablir
Ctrl + DRecopier la cellule du dessus vers le bas
Ctrl + FlècheAller au bord d'une plage de données
Ctrl + Espace / Maj + EspaceSélectionner une colonne / une ligne
Ctrl + ;Insérer la date du jour
Ctrl + Maj + LActiver ou désactiver les filtres
F4Figer une référence dans une formule ($A$1)

Le tableur sait aussi générer des séries : saisissez deux valeurs (par exemple 1 et 2, ou « Janvier » et « Février »), sélectionnez-les, puis tirez la poignée de recopie, le petit carré en bas à droite de la sélection. Il prolonge la suite logique : nombres, dates, jours de la semaine, mois.

🔢

Séries numériques

1, 2, 3… ou 10, 20, 30… selon le pas détecté.

📅

Séries chronologiques

Jours, semaines, mois ou années à la suite.

Générer une série par formule

La fonction SEQUENCE produit toute une série en une seule formule (Google Sheets et Excel récent). Ici : 5 lignes, 1 colonne, départ à 10, pas de 10.

// Série : 10, 20, 30, 40, 50
=SEQUENCE(5;1;10;10)

3. Importer et actualiser les données

Copier-coller un export à chaque mise à jour est lent et source d'erreurs. Mieux vaut connecter le tableur à la source : une fois la connexion créée, une actualisation suffit pour récupérer les données les plus récentes.

Power Query se trouve dans l'onglet Données › Obtenir des données. Il se connecte à un fichier, un dossier, une page web ou une base, puis enregistre chaque transformation (supprimer des colonnes, filtrer, changer un type) comme une étape rejouable.

  • Un clic sur Actualiser tout relance la connexion et toutes les étapes.
  • Le nettoyage n'est fait qu'une seule fois, puis appliqué automatiquement.

Google Sheets importe par fonctions, directement dans une cellule :

  • IMPORTRANGE récupère une plage d'un autre classeur Google Sheets (un accès doit être autorisé la première fois).
  • IMPORTDATA récupère un fichier CSV ou TSV publié à une adresse web.
// Plage d'un autre classeur (adresse à adapter)
=IMPORTRANGE("https://docs.google.com/spreadsheets/d/ID_DU_CLASSEUR";"Ventes!A1:D100")

// Fichier CSV hébergé en ligne (adresse à adapter)
=IMPORTDATA("https://exemple.com/ventes.csv")
⚠️ Attention

Si la source change de forme (colonne renommée, fichier déplacé), la connexion peut afficher une erreur. Une source stable et bien nommée rend l'automatisation fiable.

4. Collecte automatique avec un formulaire

Un formulaire en ligne remplace la saisie manuelle : chaque personne répond depuis son téléphone ou son ordinateur, et les réponses arrivent seules dans le tableur, une ligne par réponse, sans erreur de recopie. C'est une excellente façon d'alimenter l'étape de collecte d'une analyse.

Dans l'onglet Réponses, l'icône Google Sheets crée (ou relie) une feuille qui se remplit à chaque envoi. La première colonne enregistre l'horodatage de la réponse.

Dans l'onglet Réponses, l'option Ouvrir dans Excel génère un classeur lié au formulaire. Les nouvelles réponses y apparaissent à chaque actualisation.

💡 À retenir

Des questions à choix fermés (listes, cases) donnent des réponses homogènes, donc des données propres dès la collecte.

5. Macros et Google Apps Script

Une macro enregistre une suite d'actions (mise en forme, tri, copie) pour la rejouer en un clic ou par un raccourci. Une automatisation programmée va plus loin : elle s'exécute seule à une heure choisie ou lors d'un événement.

⏺️

Enregistrer

Le tableur mémorise vos actions pendant que vous les effectuez.

▶️

Rejouer

Un clic ou un raccourci répète toute la séquence à l'identique.

⏰

Programmer

Un déclencheur lance le script chaque jour, chaque semaine ou à chaque réponse.

  • Onglet Affichage › Macros › Enregistrer une macro : on la nomme, on réalise les actions, puis on arrête l'enregistrement.
  • Excel traduit les actions en code VBA sans que l'on ait à l'écrire.
  • Un classeur contenant des macros s'enregistre au format .xlsm.
  • Menu Extensions › Macros pour enregistrer des actions, ou Extensions › Apps Script pour ouvrir l'éditeur de code.
  • Apps Script est basé sur JavaScript et relie Sheets, Forms, Gmail ou Agenda.
  • Les déclencheurs exécutent un script automatiquement, à heure fixe ou à chaque nouvelle réponse.
⚠️ Attention

Une macro exécute des actions réelles sur vos fichiers. N'activez jamais les macros d'un document dont vous ne connaissez pas la provenance.

6. L'IA pour écrire un script simple

Un assistant d'IA peut rédiger un petit script à partir d'une description en langage courant, et expliquer ce qu'il fait ligne par ligne. Aucune connaissance préalable en code n'est requise pour comprendre le résultat, à condition de demander des commentaires.

Exemple de demande

// Demande formulée à l'IA
Écris un script Google Apps Script qui supprime les doublons
de la feuille active. Ajoute un commentaire sur chaque ligne
pour m'expliquer ce qu'elle fait, comme si j'étais débutant.

Exemple de réponse

// Nom de la fonction : elle sera lancée depuis le menu
function supprimerDoublons() {
  // On récupère la feuille actuellement ouverte
  const feuille = SpreadsheetApp.getActiveSheet();
  // On sélectionne toutes les cellules contenant des données
  const donnees = feuille.getDataRange();
  // On supprime les lignes identiques
  donnees.removeDuplicates();
}
⚠️ Erreur fréquente

Faire confiance à un script sans le comprendre. Un script qui supprime ou modifie des données doit être relu, puis essayé sur une copie du fichier, jamais directement sur l'original. Évitez aussi de transmettre à l'IA des données confidentielles : décrivez la structure, pas le contenu.

Comment obtenir un meilleur script ?

Précisez l'outil (Apps Script ou VBA), la structure du tableau (noms des colonnes), le résultat attendu et demandez des commentaires pour débutant. Une description précise donne un script plus juste.

Points clés à retenir

  • Un modèle (.xltx ou copie Google Sheets) conserve la structure d'une analyse pour la réutiliser à l'identique.
  • Les raccourcis clavier et les séries automatiques accélèrent le travail quotidien.
  • Power Query (Excel) et IMPORTRANGE / IMPORTDATA (Google Sheets) connectent le tableur à ses sources et permettent l'actualisation.
  • Un formulaire lié à une feuille alimente automatiquement les données, avec des réponses homogènes.
  • Une macro rejoue des actions ; Google Apps Script permet des automatisations programmées avec des déclencheurs.
  • L'IA peut écrire et commenter un script simple, mais l'analyste relit, teste et reste responsable du résultat.
